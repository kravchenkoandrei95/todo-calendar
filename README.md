# todo-calendar — планировщик дел

Один файл `index.html`. Сайт: https://kravchenkoandrei95.github.io/todo-calendar/ — работает с телефона и компьютера. Можно и скачать файл и открыть двойным кликом.

## Что умеет
- Задачи по дням, навигация ‹ › и кнопка «Сегодня»
- Приоритет: Срочно / Второстепенно / Можно потом (клик по метке — сменить)
- Отметка выполнения, удаление, двойной клик по тексту — редактирование
- Кольца дня: внешнее — срочные, среднее — второстепенные, внутреннее — «потом»; в центре общий %
- Прогресс: неделя с мини-кольцами, серия закрытых дней, итоги недели и 30 дней, график за 30 дней
- Перенос невыполненных задач со вчера
- Срок задачи («до 15:00», просроченные подсвечиваются красным) и категории: Работа / Колледж / Личное, фильтр по ним
- Повторяющиеся задачи: каждый день, по будням, раз в неделю (список и отключение — под задачами)
- Календарь месяца: точки — задачи дня и важные даты, клик по дню — перейти к нему
- Важные даты и дела: экзамены, совещания, дни рождения (можно «каждый год»), список ближайших 60 дней
- Кнопки «В файл» / «Из файла» — резервная копия всех данных в JSON

## Где хранятся данные
В `localStorage` браузера (ключ `todo-planner-v1`). Данные привязаны к браузеру: в другом браузере или после очистки истории их не будет.

Данные на сайте и в локально открытом файле — разные (у каждого адреса своё хранилище), между телефоном и компьютером тоже. Переносить — кнопками «В файл» / «Из файла».
